# CDet Documentation Archive

This directory preserves historical calibration records and development
summaries that are useful for provenance but are not current operating
instructions.

For current procedures, use:

- [`CDet_CROSSTARGET_TIMING_CALIBRATION.md`](../CDet_CROSSTARGET_TIMING_CALIBRATION.md)
  for the commissioned Run 5710 and Run 5992 cross-target workflow;
- [`CDet_LH2_RUN_CALIBRATION_FROM_SCRATCH.md`](../CDet_LH2_RUN_CALIBRATION_FROM_SCRATCH.md)
  for a new LH2 coincidence run;
- [`CDet_EVENT_DISPLAY.md`](../CDet_EVENT_DISPLAY.md) for the unified
  cross-target/LH2 event display; and
- the active Run 5711 and Run 6077 reports for current plots and results.

Files in this directory must not be treated as authoritative simply because
their historical titles contain words such as “final” or “calibration record.”
