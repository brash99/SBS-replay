# Run 5711 Timing-Window Diagnostic Comparison

All three analyses use the final Run 5711 calibration constants, the
`3.0 < E_ECal < 4.5 GeV` energy selection, and the `8 < ToT < 35 ns` CDet
good-hit selection. The columns differ only in the ECal and HCal ADC-time
windows shown below.

| Wide window | Nominal window | Narrow window |
|:---:|:---:|:---:|
| `-50 < t_ECal,t_HCal < 50 ns` | `-10 < t_ECal,t_HCal < 10 ns` | `-5 < t_ECal,t_HCal < 3 ns` |

## Wide-window population split

The following exploratory diagnostic separates the vertical and diagonal
components visible in the wide-window CDet-versus-ECal distribution. The
vertical selection is `-3 < t_ECal < 1 ns` and `23 < t_CDet < 40 ns`. The
disjoint diagonal selection is `1 < t_ECal < 18 ns` and
`|t_CDet - 27 - 0.73 t_ECal| < 3 ns`.

[![Wide-window Bar 30 vertical versus diagonal LE versus ToT](CDet_run5711_shift_diagnostics_wide_time_window/CDet_bar30_vertical_vs_diagonal_LE_vs_ToT.png)](CDet_run5711_shift_diagnostics_wide_time_window/CDet_bar30_vertical_vs_diagonal_LE_vs_ToT.png)

## Nominal-window ToT-threshold test

This test keeps the nominal `-10 < t_ECal,t_HCal < 10 ns` windows, the
3.0--4.5 GeV ECal energy selection, and the accepted Run 5711 calibration
constants fixed. Only the good-hit ToT interval changes from 8--35 ns to
12--35 ns. The test uses
`CDet_run5711_projection_totmin12_test.conf`; it does not replace the
authoritative Run 5711 configuration.

| Quantity | ToT 8--35 ns | ToT 12--35 ns | Retained |
|:---|---:|---:|---:|
| Good CDet events | 80,645 | 73,821 | 91.5% |
| Accepted hit pairs | 203,878 | 135,912 | 66.7% |
| Projected-half-bar pairs | 47,235 | 31,963 | 67.7% |
| Bar 30 trajectory + ToT selected hits | 4,056 | 2,871 | 70.8% |
| Bar 30 trajectory-matched peak sigma | 2.852 ns | 2.726 ns | 95.6% |
